# Checklist de assets reais

## Obrigatórios antes da versão final
1. `fibery_user_profiles.png`
   - Abrir **Discovery · User Profiles · Whiteboard** no Fibery.
   - Ajustar zoom para mostrar os mapas principais de forma legível.
   - Capturar sem menus laterais desnecessários.
   - Usar no slide de perfis; não usar o print como texto minúsculo. Pode recortar 2–4 mapas relevantes.

2. `fibery_bmc.png`
   - Abrir **Business · BMC · Whiteboard**.
   - Capturar o Canvas completo.
   - Usar como evidência de artefato; o slide pode ampliar 3 blocos-chave: segmentos, proposta de valor e receitas.

## Recomendados
3. `fibery_deliverables.png`
   - **Milet · Deliverables · Board**.
   - Serve para demonstrar organização/gestão do projeto.

4. `prototype_diagnosis.png`, `prototype_compare.png`, `prototype_tracking.png`
   - Se já existirem telas/protótipos reais, capture 2–3 telas que mostrem:
     fatura/diagnóstico → comparação → acompanhamento.
   - Se ainda não existem, NÃO inventar screenshot. Use os diagramas do pacote.

## Miro
Só use print do Miro se houver um board atual que acrescente algo que o Fibery não mostre melhor.
Evite colocar print apenas para “provar ferramenta”. O artefato precisa ajudar a explicar uma decisão do projeto.

## Tratamento visual
- Recorte bordas e chrome da ferramenta.
- Não aplique mockup 3D.
- Use sombra discreta e legenda pequena “Artefato de projeto — Fibery”.
- Nunca deixe texto do print como única fonte de informação do slide.
